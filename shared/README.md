# shared

Ten katalog zawiera biblioteki współdzielone między aplikacją MAUI, emulatorami i narzędziami.

## Co tu jest

- `Aquarium.Models/` - modele domenowe,
- `Aquarium.Protocol/` - kontrakty komunikacyjne i mappery kompatybilności,
- `Aquarium.EmulatorCore/` - silnik emulatora urządzenia.
