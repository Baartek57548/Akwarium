# tools/testy

Katalog eksperymentalny i pomocniczy. Zawiera starsze lub prototypowe narzędzia, które nie są główną ścieżką developerską projektu.

- `Aquarium.ControllerEmulator/` - analityczny emulator UI oparty o parser C++,

- `akwarium-ui/` - artefakty front-endowe i buildy pomocnicze.
